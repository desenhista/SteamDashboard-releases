# Dashboard

Interface de tela cheia, navegável pelo controle, para a biblioteca da Steam e para jogos de outras plataformas (Xbox, Epic, EA, Ubisoft ou adicionados à mão), no lugar do Big Picture.

Este repositório só guarda os downloads. Baixe a versão mais recente em [Releases](https://github.com/desenhista/SteamDashboard-releases/releases).

## Instalação
1. Baixe o `Dashboard-<versão>-win-x64.zip` do Release mais recente e extraia em uma pasta onde você tenha permissão de escrita (por exemplo, `C:\Jogos\Dashboard`, não em Arquivos de Programas).
2. Abra o `Dashboard.exe`.

Requisitos: Windows 10 ou 11 (64 bits) e o WebView2 Runtime, que já vem com o Windows 11. O .NET 8 vem embutido.
